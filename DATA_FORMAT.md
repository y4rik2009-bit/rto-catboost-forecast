# Структура входных данных

Поместите разрешённый к использованию файл `train_2.csv` в локальную папку `data/`. Этот документ описывает схему, **не содержит строк настоящего датасета**.

- Формат: CSV с запятыми и строкой заголовков, кодировка UTF-8.
- Одна строка: один объект (`new_id`) за один календарный месяц.
- Обязательные столбцы: `new_id`, `Год`, `Месяц`, `РТО`.
- `new_id`: числовой идентификатор объекта; не должен отсутствовать.
- `Год`: 2023, 2024 или 2025. `Месяц`: целое число от 1 до 12.
- На каждый `new_id` нужны ровно 26 строк: все месяцы с января 2023 по февраль 2025, без повторов.
- `РТО`: положительное конечное число за текущий месяц; февраль 2025 тоже должен быть известен.
- Остальные столбцы: числовые или категориальные признаки текущего месяца. Строковые категории, в том числе населённый пункт и регион, передаются CatBoost; числовые признаки участвуют и в линейной модели.

Заголовок исходного файла также включает средние количества товаров и отмен, рабочие часы, группы торговой площади и даты открытия, населённый пункт, регион, численность населения, домохозяйства, пеший и автомобильный трафик, соседние объекты, число касс и флаг алкогольной лицензии. Код определяет категориальные столбцы по типу данных. Названия столбцов должны совпадать с вашими данными; переименовывать их в README не нужно.

Скрипт использует данные текущего месяца для прогноза следующего. Проверьте происхождение каждого признака: значение, рассчитанное с привлечением будущих месяцев, внесёт утечку информации даже при правильном разбиении строк по времени.
